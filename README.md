# TWRP device tree for Xiaomi dash

TWRP for Redmi Turbo 5 Max. Maybe works on Poco too.

## Working

- [x] ADB
- [x] Decryption
- [x] Fastbootd
- [x] Haptics
- [x] MTP
- [x] Touch
- [x] USB-OTG
